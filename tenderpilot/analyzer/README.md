# TenderPilot — Tender Analyzer

أول وحدة إنتاجية في TenderPilot AI. ترفع كراسة الشروط (PDF) فتحصل على:

- **موجز منظّم:** المتطلبات (فنية، خبرات، شهادات، كوادر، مالية، إدارية، محتوى محلي)، الضمانات، معايير التقييم، المخاطر، مسببات الاستبعاد الشكلي، التواريخ، وأسئلة استيضاح.
- **مصدر لكل بند:** رقم الصفحة والبند واقتباس حرفي، **يُتحقق منه آلياً** مقابل نص الملف.
- **Opportunity Score (0–100)** قابل للتفسير عند إرفاق ملف الشركة، مع توصية Go / Review / No-Go.
- **تقرير تنفيذي** بالعربية (Markdown) جاهز للمراجعة.

هذه الوحدة تخدم "الإسفين الخدمي" في [دليل أول إيراد](../business/TenderPilot_Go_To_Revenue_Playbook.md): تقلّص زمن تحليل الكراسة من ساعات إلى دقائق، فترتفع هوامش الخدمة، ثم تصبح أساس منتج SaaS.

## خط المعالجة

```
PDF ─► load_pdf (حجم/صفحات + طبقة نصية)
    ─► extract  [LLM: claude-opus-5-5, effort=high]   → TenderExtraction (مخطط Pydantic)
    ─► verify_sources [كود]                            → التحقق من الاقتباسات
    ─► assess   [LLM: claude-opus-5-5, effort=medium] → حالة كل متطلب مقابل ملف الشركة
    ─► compute_score [كود]                             → درجة + عوامل + فجوات حاجبة
    ─► render_markdown [كود]                           → التقرير التنفيذي
```

### قرارات التصميم

| القرار | السبب |
|---|---|
| **مخرجات منظّمة** (`output_format=PydanticModel`) | الاستجابة مضمونة المطابقة للمخطط؛ لا تحليل نصي هش. |
| **الدرجة تُحسب بالكود لا بالنموذج** | النموذج يحكم على *استيفاء* كل متطلب؛ الأوزان في `scoring.py` تحت التحكم بالإصدارات. كل نقطة تظهر كعامل مفسَّر، ومجموع العوامل يساوي الدرجة (مُختبَر). |
| **أي متطلب إلزامي غير مستوفى يحدّ الدرجة عند 39** | عرض قد يُستبعد لا ينبغي أن يظهر كـ Go مهما كانت بقية النقاط. |
| **`unknown` بدل التخمين** | يعرف فريق العطاءات ما يجب التحقق منه داخلياً، وتنخفض "الثقة" تلقائياً. |
| **التحقق من الاقتباسات** | مكافحة الهلوسة: تطبيع عربي (أشكال العرض، التشكيل، التطويل، الهمزات، الأرقام الهندية) + مطابقة تقريبية تتحمل ترتيب الكلمات المعكوس في طبقات PDF. الملفات الممسوحة تُعلَّم "تحتاج مراجعة يدوية". |
| **توجيه حسب المهمة** (`TP_<TASK>_MODEL/EFFORT/MAX_TOKENS`) | كل خطوة قابلة للنقل لنموذج أو مستوى جهد آخر بلا تعديل كود، بعد قياس الجودة. |
| **Prompt caching** | موجّهات النظام ثابتة البايتات ومخزّنة مؤقتاً؛ وكتلة الـ PDF مخزّنة لإعادة التحليل. |
| **Streaming** | الكراسات الطويلة والمخرجات الكبيرة دون مهلات HTTP. |
| **Refusal fallbacks + أخطاء مصنّفة** | `fallbacks: "default"` على Claude API؛ الرفض والاقتطاع يرفعان استثناءات واضحة تتحول لرموز HTTP مناسبة. |
| **وثيقة الكراسة = مدخل غير موثوق** | الموجّه ينص على معاملة محتواها كبيانات لا تعليمات (حماية من حقن الأوامر). |
| **مزود Foundry** (`TP_PROVIDER=foundry`) | تشغيل داخل Azure لإبقاء البيانات ضمن مستأجر العميل (متطلبات السيادة/PDPL). يعطّل الـ fallbacks تلقائياً لأنها خاصة بـ Claude API. |

## التشغيل

```bash
cd tenderpilot/analyzer
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env   # ضع ANTHROPIC_API_KEY أو استخدم `ant auth login`

# سطر الأوامر
tenderpilot-analyze tender.pdf --profile examples/company_profile.json -o report.md --json analysis.json

# واجهة HTTP
uvicorn tenderpilot_analyzer.api:app --reload
curl -F file=@tender.pdf -F company_profile="$(cat examples/company_profile.json)" \
     "http://localhost:8000/v1/analyze?format=markdown"
```

Docker:

```bash
docker build -t tenderpilot-analyzer .
docker run -p 8000:8000 -e ANTHROPIC_API_KEY tenderpilot-analyzer
```

## الاختبارات

```bash
pytest
```

تغطي الاختبارات: الدرجة والعوامل والحدود، تطبيع النص العربي والتحقق من الاقتباسات، خط المعالجة كاملاً بنموذج وهمي، شكل الطلب المرسل للـ API (النموذج، الجهد، المخطط، التخزين المؤقت، الـ fallbacks)، معالجة أسباب التوقف، وواجهة HTTP. لا تستدعي الاختبارات الـ API الحقيقي.

## قبل الإنتاج

1. **مجموعة تقييم (Eval):** 20–30 كراسة حقيقية مع موجز مُراجَع بشرياً، لقياس دقة الاستخراج قبل خفض الجهد أو تغيير النموذج.
2. **معالجة غير متزامنة:** تحليل كراسة طويلة يستغرق دقائق؛ انقل `/v1/analyze` إلى طابور مهام (Azure Service Bus) مع حالة مهمة.
3. **مصادقة وعزل المستأجرين** على الواجهة، وتسجيل تدقيق لكل تحليل.
4. **التحقق من دعم Foundry** للمخرجات المنظّمة في منطقتك قبل اعتماد `TP_PROVIDER=foundry`.
