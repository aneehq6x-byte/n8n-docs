## ما تم تنفيذه

- **الاشتراكات**: خطط (شهري متجدد 30 يومًا بالنجوم، 3/6/12 شهرًا كمدد وصول)، تجربة مرة واحدة،
  كوبونات بحدود، تكديس التجديد، انتهاء، تذكيرات، إيقاف التجديد مع بقاء الوصول.
- **المدفوعات**: فاتورة موقعة HMAC، pre-checkout صارم، معالجة idempotent، دفتر قيود إلحاقي،
  استرداد عبر `refundStarPayment` قبل التسجيل، تجديدات Stars المتكررة كدفعات منفصلة، `/paysupport`.
- **العضوية**: روابط بطلب انضمام لكل مستخدم، رفض الروابط المشتركة/المنتهية/المستخدمة،
  إزالة المنتهين (ban+unban) مع مهلة، العودة بعد التجديد، سجل تدقيق.
- **البيانات**: Protocol موحد، Mock موسوم، محول Massive (غير مختبر حيًا)، فحص التقادم، صحة المصدر.
- **الكمي**: SMA/EMA/RSI/MACD/ATR/ADX/VWAP/Anchored VWAP/RVOL/Opening Range/PDH-PDL/Swing/
  Volatility regime — سببية ومختبرة؛ استراتيجيتا ORB وVWAP Trend؛ Backtester صادق (EXPIRED،
  الوقف أولًا، التكاليف)، مقاييس، Walk-forward، بوابة قبول OOS، Monte Carlo.
- **الخيارات**: Black-Scholes + Greeks + IV؛ مواصفات SPX≠SPY؛ اختيار العقد بعد السبريد والانزلاق
  والرسوم وTheta وIV crush؛ ضوابط 0DTE.
- **المخاطر**: 15+ قاعدة بقيم محافظة؛ 0DTE معطل افتراضيًا؛ لا استراتيجية مفعّلة افتراضيًا.
- **الإشارات**: دورة حياة كاملة، سجل إلحاقي، أصل غير قابل للتعديل، وضع موافقة بشرية افتراضي،
  Outbox بلا تكرار + Dead letter، قوالب عربية بتوقيت ET والرياض ومصدر البيانات.
- **الذكاء الاصطناعي**: سجل 11 وكيلًا بصلاحيات صريحة؛ مساعد بأدوات قراءة فقط، تحقق رقمي يحجب
  الأرقام المختلقة، معالجة الرفض، حصص يومية، fallback من جهة الخادم.
- **التشغيل**: Admin API (RBAC)، Kill switch، فحوص أمان الإنتاج تمنع الإقلاع، Alembic، Docker،
  Compose، CI.

## قرارات تحتاجك

1. **الترخيص** (CMA): أي مسار؟ ترخيص، شريك مرخص، أم محتوى تعليمي فقط؟ — حاسم قبل أي شيء تجاري.
2. **مزود البيانات وخطة إعادة النشر** — يتطلب طلب عرض سعر (Massive Business / Cboe / Databento).
3. **أسعار الخطط بالنجوم** — الأسعار الحالية في `seed` افتراضية للاختبار.
4. **نموذج الذكاء الاصطناعي** — الافتراضي `claude-opus-5-5`؛ نموذج أرخص يخفض التكلفة كثيرًا (قرارك).
5. **نقل المشروع لمستودع خاص مستقل** — هو حاليًا مجلد داخل مستودع n8n-docs على فرع منفصل.
