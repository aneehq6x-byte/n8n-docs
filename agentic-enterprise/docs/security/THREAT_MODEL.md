# نموذج التهديد (Threat Model)

- **النطاق:** المنصة والوكلاء الخمسة في `agentic-enterprise/`، بإصدار ما بعد ADR-009.
- **المنهج:** STRIDE لكل حد ثقة، مع تصنيفات OWASP Top 10 for LLM Applications (LLM01 إلى LLM10). المراجع إطار عمل هندسي، وليست ادعاء امتثال.

## 1. الأصول

| الأصل | لماذا هو مهم |
|-------|--------------|
| أموال الشركة | الدفعات وأوامر الشراء لا رجعة فيها |
| سجل audit | الدليل الوحيد على من قرر ماذا، والأساس القانوني للمساءلة |
| قرارات الموافقة | الضمانة البشرية الوحيدة على الإجراءات التي لا رجعة فيها |
| بيانات الموردين الرئيسية | الحسابات البنكية هي هدف الاحتيال الأول |
| نتائج فحص العقوبات | التبرئة الخاطئة مخالفة قانونية جسيمة |
| مفاتيح: مفتاح تثبيت audit، ومفاتيح الموافقين الخاصة، ومفتاح Claude | الاستيلاء عليها يُسقط ضمانات كاملة |

## 2. حدود الثقة

```
[محتوى خارجي: بريد، فواتير، عروض] ──غير موثوق──► [النموذج] ──غير موثوق──► [ToolExecutor] ══حد الإنفاذ══► [Connectors]
                                                                              │
[الإنسان + مفتاحه الخاص] ──موقّع──► [Approval Gate] ◄─────────────────────────┘
                                         │
[ملف القاعدة] ◄── موثوق جزئيًا ──► [Audit] ──► [ملف التثبيت + مفتاح HMAC (خارج القاعدة)]
```

## 4. مخاطر مقبولة مؤقتًا (بقرار موثق)

1. **تسجيل المفاتيح:** `platform_operator` يستطيع تسجيل مفتاح باسم موافق.
   - **التخفيف:** audit، والبصمة ظاهرة، والتحقق خارج النظام.
   - **الإغلاق:** ربط المفاتيح بمزود الهوية.
2. **`submit` غير موقّع:** الطالب يستطيع انتحال طالب آخر عند الإرسال.
   - **التخفيف:** الطلب لا يحرّك شيئًا دون موافقة موقّعة، ومنشئ السلسلة ممنوع من اعتمادها.
3. **الوضع الحي غير مقيس** على سلوك نموذج فعلي.
   - **الإغلاق:** تشغيل `eval --live` بعد توفير المفتاح.
